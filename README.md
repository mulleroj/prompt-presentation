# Gemini Notebook – Generátor promptů pro prezentace

Lokální aplikace pro přípravu obsahového promptu a nastavení prezentace v Gemini Notebooku. Aplikace nepoužívá API; zadaná data zůstávají v prohlížeči.

## Základní postup

1. Vyplňte zadání prezentace.
2. Nastavte uvedené hodnoty v Gemini Notebooku.
3. Zkopírujte vlastní prompt.
4. Vložte jej do generování prezentace.

Aplikace nabízí Jednoduchý a Pokročilý režim. Umožňuje také používat předvolby a importovat či exportovat jejich data ve formátu JSON.

Technologie: HTML, CSS a vanilla JavaScript.
